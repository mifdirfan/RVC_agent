# Event List

## Format

| Input/Output Event | Description |
|---|---|
| Event Name | Event Description |

## Example

| Input/Output Event | Description |
|---|---|
| Front Sensor Input | Detects obstacles in front of the RVC. |
| Left Sensor Input | Detects obstacles on the left side of the RVC periodically. |
| Right Sensor Input | Detects obstacles on the right side of the RVC periodically. |
| Dust Sensor Input | Detects dust on the floor periodically. |
| Direction | Sends movement commands to the motor. |
| Clean | Sends cleaning commands to the cleaner. |

## Formatting Rules
- Use a Markdown table.
- Use exactly two columns:
  Input/Output Event and Description.
- Include one event per row.
- Use concise and meaningful event names.
- Describe the purpose of each event clearly.
- Include input and output events in the same table.
